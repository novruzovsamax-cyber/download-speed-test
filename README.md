# download-speed-test

Консольный скрипт для замера скорости скачивания. Делает 10 последовательных
запросов к адресу, дожидается полного ответа на каждый и печатает среднее
время запроса, общий объём скачанных данных и скорость.

## Запуск

Нужен Node.js 18 или новее. Зависимостей нет, `npm install` не требуется.

```bash
git clone https://github.com/novruzovsamax-cyber/download-speed-test.git
cd download-speed-test
node speedtest.mjs "https://speed.cloudflare.com/__down?bytes=10000000"
```

Адрес берите в кавычки: без них символ `&` в адресе ломает команду.
Подойдёт любой тяжёлый файл, от 10 МБ. На маленьком время уходит в основном
на установку соединения, и скорость получается заниженной.

## Пример вывода

```
Адрес: https://speed.cloudflare.com/__down?bytes=10000000
10 запросов подряд, каждый по новому соединению

 1/10     10.00 МБ    1569 мс    51.0 Мбит/с
 ...
10/10     10.00 МБ    2686 мс    29.8 Мбит/с

Успешных запросов: 10 из 10
Среднее время запроса: 1820 мс (мин 1365 мс, макс 3524 мс)
Скачано всего: 100.00 МБ (100000000 байт)
Скорость скачивания: 44.0 Мбит/с (5.50 МБ/с)
```

## Единицы

- **Скорость — Мбит/с**, как у провайдеров. В скобках то же в МБ/с.
- **Объём — МБ**, 1 МБ = 1 000 000 байт (десятичные единицы, не МиБ).
- **Время — мс.**

## Как считается

- **Время запроса**: от отправки запроса до последнего байта ответа,
  включая установку соединения и редиректы.
- **Объём**: байты тела ответа, реально полученные по сети (без сжатия).
- **Скорость** = общий объём / суммарное время успешных запросов.

Каждый запрос идёт по новому соединению, поэтому все 10 в одинаковых
условиях. Запросы последовательные, так что это скорость одного соединения:
speedtest-сервисы качают в несколько потоков и могут показать больше.

Ответы с ошибкой (404, 429 и т. п.) не считаются скачанными данными и не
входят в статистику. Если сервер 30 секунд не присылает данных, запрос
считается неудачным.
